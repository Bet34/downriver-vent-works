# Downriver Vent Works

High-converting dryer vent cleaning landing page for Downriver / Wayne County, Michigan.

After GitHub Pages is on: `https://bet34.github.io/downriver-vent-works/`

## Before paid traffic

1. Replace `(734) 555-0194` with a real tracking number.
2. Replace `YOUR_FORM_ID` in the form action with a Formspree form ID.
3. Replace placeholder testimonials with real Google reviews.
4. Add license / insurance numbers.
5. Uncomment GA4 and paste your Measurement ID.

Copy `index.html` from this repo root. Enable Pages: Settings → Pages → Deploy from branch → main / root.
